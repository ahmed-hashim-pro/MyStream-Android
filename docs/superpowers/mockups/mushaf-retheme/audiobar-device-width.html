Audio bar at device width — 412dp redesign

The chosen A (stopped) / B (playing) bar, re-proportioned on the real emulator canvas (412×914dp) instead of the 312px option frames. The fix is an alignment system: one shared 16dp content inset for every row of the bar. Deck text and filled shapes (avatar chip, gold FAB) sit exactly on it; the borderless control icons align optically — their 48dp touch boxes are inset 4dp so the glyph edge lands on the same 16dp line, and the six controls distribute edge-to-edge inside that box (no more half-cell drift).
