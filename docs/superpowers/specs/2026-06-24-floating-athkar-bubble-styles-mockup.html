What this is

  • One feature, three interchangeable styles: A Chat-head, C Edge drawer, D Mini-pill.
  • Chosen in AthanSettingsActivity (a new “Floating bubble” section), persisted in SharedPreferences (e.g. bubble_style).
  • The floating overlay reads that pref and renders the chosen style — same content + counters either way.

Build reality (from the scan)

  • ✅ SYSTEM_ALERT_WINDOW + overlay-grant UX already exist (this picker lives right beside it).
  • ✅ FGS template AthanPlaybackService; content/counters from AthkarActivity + TasbihActivity.
  • 🆕 New: the WindowManager overlay with 3 swappable layouts.
  • ⚠︎ FGS = persistent notification + Play “special use” justification.
