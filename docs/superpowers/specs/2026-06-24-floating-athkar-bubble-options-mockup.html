Floating Athkar Bubble — pick a view

Five takes on the same feature: a floating day & night athkar companion over other apps. Same content (AthkarActivity morning/evening), same tokens — only the shape of the interaction differs. Tap each phone to open/interact; counters work. Toggle Session / Theme / Language for all at once.

AChat-head + walker
Closest to Messenger. Familiar ball → focused one-dhikr counter panel. Drag enabled here.
BRadial hub
Bubble as a launcher. Tap fans out Day / Night / Tasbih / Dua — one bubble, many shortcuts.
CEdge peek drawer
Docks to the edge. A slim tab → slides out the whole set as a list; tap a row to count it.
DGlanceable mini-pill
Readable at rest. Shows the current dhikr + count without tapping; tap to expand the walker.
EFloating swipe-cards
Story-like. Swipe one dhikr per card; the floating cousin of the stored Stories feature.

How they differ — to help you pick

AMost familiar / least surprising. Best if you want “the Messenger bubble, but athkar.” One dhikr at a time, big counter.
BMost versatile. Best if the bubble should be a hub for several quick actions, not only athkar.
CBest overview. See the whole set at once; least “game-y”, most utilitarian. Good for fast tap-through.
DMost informative at rest. You read/advance the dhikr without even opening it. Slightly larger footprint.
EMost beautiful / immersive. Matches the Stories feel; great for focus, less for speed.
