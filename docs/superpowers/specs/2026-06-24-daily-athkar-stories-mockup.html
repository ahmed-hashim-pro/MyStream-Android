Resets every day. This is the app’s first per-day engagement state (new SharedPreferences keys). The glowing ring is what creates the “unseen story” pull.

How it maps to your codebase

  • Home strip → same dynamic horizontal rail as the prayer pills (bindPrayerTimeline()), inserted into fragment_home.xml above “Verse of the Day”.
  • Content → reuses AthkarActivity.getAthkarList() morning/evening sections via a new accessor — one source of truth, no duplication.
  • Counters → reuse the existing tasbih count-down logic per dhikr.
  • Active window → PrayerTimeEngine.getTodayTimes(): Morning glows after Fajr, Evening glows after Asr.
  • Story viewer → new full-screen Activity with a hero-style header.

Decisions baked into this mock (tell me to change any)

  • 2 bubbles, Morning + Evening; current one glows, other dims.
  • Full guided session — swipe the whole set, count each dhikr.
  • Daily seen/unseen ring + completion tracking.
  • Leading streak chip 🔥 in the strip (optional — easy to drop).
